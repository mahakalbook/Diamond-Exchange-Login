## Common Login Problems

### Incorrect Password

An incorrect password is one of the most common reasons for failed login attempts. Recheck the spelling, capitalization, and any accidental spaces.

### Wrong ID

Make sure you are entering the correct Diamond Exchange ID or username associated with your account.

### Website Not Loading

If the login page does not open, check your internet connection and refresh the page. You can also try clearing browser cache or using an updated browser.

### Mobile Browser Issues

If you are accessing the website from a phone, make sure your browser is updated. Switching between Wi-Fi and mobile data can also help identify connection-related problems.

### Verification Problems

Some accounts may require additional verification. If verification remains pending, contact the appropriate support channel instead of repeatedly submitting information.
